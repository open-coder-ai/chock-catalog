# Support

- **Questions and ideas** → [Discussions](https://github.com/open-coder-ai/chock-catalog/discussions).
- **A policy behaves wrongly** → [open an issue](https://github.com/open-coder-ai/chock-catalog/issues/new/choose)
  using the "Policy wrong" template, with the command that misfired.
- **Propose a new guardrail** → the "Policy proposal" template.
- **Security vulnerabilities** (in a guard script, or a policy that under-blocks what it
  claims to block) → [private security advisory](https://github.com/open-coder-ai/chock-catalog/security/advisories/new),
  never a public issue. Details in [SECURITY.md](SECURITY.md).
- **The framework itself** (`chock` CLI, compiler, validation) →
  [open-coder-ai/chock](https://github.com/open-coder-ai/chock).

No paid support or SLA; maintainers aim to give first feedback within a few days.
